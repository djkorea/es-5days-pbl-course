# Day 5 — ES|QL, AI Search 판단, 검증·발표

오늘은 ES|QL의 기본 분석 흐름을 확인하고, AI Search 적용 여부를 이론적으로 판단한 뒤 최종 제출을 정리합니다.

## 완료 기준

- ES|QL 요청 1개를 실행했다.
- AI Search 적용 여부와 근거를 README에 적었다.
- 최종 테스트, Dashboard 증거, `SUBMISSION.md`의 commit SHA를 확인했다.
- 3~5분 데모 발표를 준비했다.

AI Search는 이론·기업 활용사례·설계 판단만 다룹니다. 임베딩·벡터·semantic search 실행 환경은 이 과정에서 제공하지 않습니다.

## 제공 자료

- `requests/06-esql-category-summary.json`: category별 상품 수와 평균 가격을 확인하는 ES|QL 요청 본문

- [학생교재](student-workbook.md): ES|QL, AI Search 판단, 최종 검증·제출·발표 안내

최종 AI Search 강의는 이론·사례·설계 판단으로 진행했습니다. 교재의 활동은 복습 참고이며 새 구현 과제나 추가 평가 요구가 아닙니다.
